# SpaceAero — how to publish an article

1. In this repo on GitHub, open the `_posts` folder.
2. Click **Add file → Create new file**.
3. Name it `YYYY-MM-DD-short-title.md` (e.g. `2026-11-14-starship-flight-test.md`).
4. Paste this at the top, then write the article below it:

```
---
layout: article
title: "Your article title"
summary: "One sentence that appears on the homepage list."
---

Write here. A blank line starts a new paragraph.

## A section heading

- bullet points start with a dash
```

5. Click **Commit changes**. The article appears on spaceaero.org within a couple of minutes.

Unfinished pieces can go in `_drafts` — files there are never published.
